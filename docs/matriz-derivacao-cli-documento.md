# Matriz de derivação — `ies documento *`

Parte da [matriz de derivação da CLI](matriz-derivacao-cli.md), com os
mesmos estados, a mesma regra de priorização e o mesmo critério de
contagem (estes 4 caminhos estão entre os 19). Separada por tamanho, como
a [matriz da unidade](matriz-derivacao-cli-unidade.md). Os links relativos
valem a partir de `docs/`.
