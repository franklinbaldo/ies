## Cache local padrão (#236)

A leitura de cada documento grava representação integral por host,
número SEI, versão observada e SHA-256, independentemente de `--saida`.
Sem versão observada, usa `x-` e não faz GET adicional apenas para
construir o nome. `--sem-cache` e `IES_CACHE_DOCUMENTOS=0` desligam
a persistência. `--saida` é cópia opcional, com link físico ou
fallback privado. JSON inclui `cache` e `crc_rodape`.
A validação ao vivo segue NOT_RUN até ensaio autorizado.
