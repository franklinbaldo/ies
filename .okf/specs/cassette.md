# Cassette

Representa uma revisão completa de cassette gravada em ambiente público do SEI. `source_zip` é o URL do ZIP no Internet Archive; `archive_member` é o JSON interno; `archive_sha1` verifica o ZIP; `cassette_sha256_lf` verifica o JSON após normalização CRLF→LF. `installation` é unb, ufrj, go ou pen1–pen4; `interactions`, `complete` e `schema_version` são dados observados. O card não certifica uma operação de escrita sem conferência pós-efeito.
